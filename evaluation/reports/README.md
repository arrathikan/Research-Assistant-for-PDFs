# Evaluation Reports (`evaluation/reports/`)

This directory persists versioned, reproducible evaluation reports generated by offline Ragas benchmarking suites (AGENTS.md Rule 10).

---

## File Naming Convention

Reports should be saved as timestamped Markdown and JSON files:
- `YYYY-MM-DD_hybrid_vs_semantic.md`
- `YYYY-MM-DD_hybrid_vs_semantic.json`

## Required Report Fields

Every evaluation run report must document:
- Date, time, and Git commit hash evaluated.
- Pipeline configuration (retriever parameters, $k$, LLM temperature).
- Faithfulness, Answer Relevancy, Context Precision, and Context Recall scores.
- Spot-check manual verification notes.
