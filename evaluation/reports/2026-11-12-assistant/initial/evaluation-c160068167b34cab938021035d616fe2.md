Reference: Models often struggle to use relevant information in the middle. When the same input fits both base and extended-context counterparts, performance is nearly identical. Answer: The paper concludes that a larger context window expands how much information a model can accept, but does not ensure that the model can effectively find and use the relevant information. Across its tasks, performance changes substantially with the position of that information: models often perform best when it appears at the beginning or end of the context and worst when it is in the middle. \[1\] \[2\]<br><br>A longer context can therefore create an additional reasoning burden: it supplies more material that the model must process, including irrelevant content, which can reduce accuracy rather than improve it. The paper characterizes longer-context prompting as a trade-off whose value depends on both the usefulness of the added information and the model’s ability to use it. \[3\] \[4\]<br><br>Importantly, the problem is not simply that extended-context models have smaller effective windows.
